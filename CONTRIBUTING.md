# Contributing to NTZero

NTZero is an experimental operating-system project.

## Good first contributions

- Reproduce QEMU boot bugs
- Improve documentation
- Add diagnostics
- Fix compiler warnings
- Add driver tests
- Report hardware compatibility

## Bug reports

Please include the NTZero version, host OS, QEMU version, exact QEMU command, CPU/machine configuration, serial output and reproduction steps.
