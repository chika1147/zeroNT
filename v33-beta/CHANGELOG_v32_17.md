# zeroNT v32.17 - Explorer Fit Fix

- Fixed the Explorer classic toolbar overflowing outside the right edge of the window.
- Narrow Explorer windows now wrap the toolbar into two rows.
- Wide Explorer windows keep the original single-row classic layout.
- Address bar and file list move down automatically when the toolbar wraps.
- Mouse hit-testing, drag/drop-to-Delete, scrolling, and Explorer selection use the same responsive layout.
- No drivers, filesystem, installer, user, audio, network, scheduler, or background processing were removed.
- Keeps v32.16 QEMU low-memory launcher settings and the v32.15 paced boot display.
