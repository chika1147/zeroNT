# NTZero Alpha 0.1

NTZero Alpha 0.1 is the first public developer preview.

## Current public baseline

```text
Architecture : x86_64
Firmware     : UEFI
Kernel image : PE32+ NT Native
Kernel base  : 0x10000000
Emulator     : QEMU (primary runtime target)
Release      : Alpha
Version      : 0.1.0-alpha
```

The source tree contains a real UEFI loader, native-kernel entry path, serial diagnostics and an ALPC transport core. It remains early development software and is not intended for production use.
