# NTZero Roadmap

## Alpha 0.1

- Public repository baseline
- QEMU-first development target
- UEFI/x86_64 project structure
- Kernel and driver source organization
- Reproducible run scripts

## Alpha 0.x

- Stabilize boot path
- Stabilize exceptions and interrupts
- Memory manager improvements
- APIC / SMP improvements
- Scheduler improvements
- Ring 3 execution
- System call layer
- Native process / thread objects
- LPC / ALPC-style IPC

## Beta

- Stable VFS
- Storage drivers
- USB HID
- Network stack
- User applications
- Native GUI
- Broader hardware testing

## 1.0

- Stable boot/install path
- Defined supported hardware
- Stable user/kernel ABI
- Installer and recovery path
- Release documentation
